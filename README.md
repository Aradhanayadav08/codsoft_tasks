# CODSOFT Artificial Intelligence Internship Tasks

This repository contains three Artificial Intelligence internship tasks completed for CodSoft.

## Tasks Completed

### Task 2: Tic-Tac-Toe AI
An unbeatable Tic-Tac-Toe game using the Minimax algorithm.

### Task 3: Image Captioning AI
A web app that generates captions for uploaded images using a pre-trained BLIP model.

### Task 4: Recommendation System
A content-based movie recommendation system using TF-IDF and cosine similarity.

## Technologies Used
- Python
- Streamlit
- Hugging Face Transformers
- PyTorch
- Pandas
- Scikit-learn
- Minimax Algorithm
- TF-IDF
- Cosine Similarity
