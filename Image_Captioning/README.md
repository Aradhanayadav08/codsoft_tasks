# Image Captioning AI

A Streamlit web app that generates natural language captions for uploaded images using a pre-trained BLIP vision-language model.

## Technologies Used
- Python
- Streamlit
- Hugging Face Transformers
- BLIP Model
- PyTorch
- Pillow

## How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Features
- Upload image
- Generate AI-based caption
- Simple web interface
- Uses pre-trained model
