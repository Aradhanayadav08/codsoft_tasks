# Tic-Tac-Toe AI

An unbeatable Tic-Tac-Toe game where the computer uses the Minimax algorithm to choose optimal moves.

## Technologies Used
- Python
- Minimax Algorithm
- Game Theory

## How to Run
```bash
python tic_tac_toe.py
```

## Features
- Human vs AI gameplay
- AI makes optimal decisions
- Win/draw detection
- Console-based clean interface
